# Page Turner

PCのKindleで漫画を読むときに、Androidスマホの**音量ボタンでページをめくる**リモコンアプリです。
スマホがPCから「Bluetoothキーボード」として見えるので、PC側にソフトを入れる必要はありません。

| 操作 | 動作 | 振動 |
|---|---|---|
| 音量＋ | 次のページ | 短く1回 |
| 音量− | 前のページ | 短く2回 |
| （未接続で押した） | なし | 長く1回 |

## 動作環境

- Android 9 以上（iPhoneでは作れません。iOSにはアプリがBluetoothキーボードになるための仕組みがないため）
- Bluetooth付きのWindows PC

## インストール

1. スマホのブラウザで、GitHubリポジトリの **Releases → `page-turner-latest`** を開き、`PageTurner.apk` をダウンロードする
2. 「提供元不明のアプリ」のインストールを許可して開く

> ビルドするたびに署名が変わるため、新しい版を入れるときは古いアプリをアンインストールしてから入れてください。

Android Studioで `page-turner/` フォルダを開いて実機に直接インストールしてもかまいません。

## 使い方

### 初回（PCの登録）
1. アプリを起動し、権限を許可する
2. 「＋ 新しいPCを登録する」をタップ → 表示を許可
3. PCで **設定 → Bluetooth とデバイス → デバイスの追加 → Bluetooth** を開き、スマホの名前を選ぶ
4. つながると読書画面（真っ黒な画面）に切り替わる

### 2回目以降
アプリを起動するだけで前回のPCに自動でつながります。

### 読書画面のボタン
- **向き**：`右開き（漫画）` ←キーで次へ ／ `左開き` →キーで次へ ／ `PageDown/Up`
  - めくる方向が逆なら、ここをタップして切り替えます
- **画面**：`暗く点灯`（初期値）だと画面を最低輝度で点けっぱなしにします。
  `自動消灯` にすると画面が消えても動きますが、端末によっては消灯中に音量ボタンが届かないことがあります
- **切断**：PCとの接続を切る

通知の「終了」かアプリの「アプリを終了」で完全に止まり、音量ボタンが元の音量操作に戻ります。

## うまくいかないとき

- **以前このスマホをPCとペアリングしたことがある場合**：PCのBluetooth設定からスマホを一度「デバイスの削除」してから、登録し直してください（キーボードとして認識させ直すため）
- **他の「Bluetoothキーボード」系アプリ**が動いていると登録に失敗します。終了させてください
- 一部の機種（古いXperiaなど）はBluetoothキーボード機能（HID Device）が無効化されていて使えません

## 構成

```
app/src/main/java/com/namek/pageturner/
  HidKeyboard.kt     Bluetoothキーボードとして登録・接続・キー送信
  PageTurnService.kt 常駐サービス。MediaSession で裏でも音量ボタンを受ける
  PageTurner.kt      次へ/戻るのキー送信と振動
  MainActivity.kt    接続画面と読書画面
  Prefs.kt           向き・前回のPC・画面設定の保存
```
